## Selected Work

### [OptiLog — Logistics Process Intelligence](https://github.com/h4nsx/Vyn-Logistic)

An AI-powered platform that turns logistics event logs into operational insight. It reconstructs workflows from uploaded data and helps surface process anomalies, bottlenecks, and risk patterns — without requiring users to manually define each workflow.

**What I explored:** event-driven data processing, process discovery, anomaly detection, and turning model output into actionable operational information.

[Live demo](https://vyn-logistic.vercel.app)

### [YOLO-Mamba Research](https://github.com/h4nsx/nckh)

Research into replacing YOLO11s' self-attention block with a 2D selective state-space module for warehouse object detection on constrained hardware.

The work investigates an important engineering trade-off: a model can have fewer parameters and lower theoretical computation while still running slower on a CPU. The experiments compare detection quality, model size, memory use, and real-device latency.

**Research focus:** efficient model architecture, reproducible experiments, and edge inference performance.

### [SafeSwap — Aptos DeFi Safety](https://github.com/h4nsx/SafeSwap-Token)

A token-swapping experience for the Aptos ecosystem with scam detection designed to help users assess token risk before interacting with a swap.

I contributed as team leader, working on machine-learning direction and team coordination. The project received student-project recognition at the 2025 Aptos hackathon.

### Global AI Brain — Smart Warehouse Perception

An intelligent warehouse concept focused on multi-camera perception and a shared spatial understanding of warehouse activity. The system explores how camera streams can support tracking of workers, forklifts, autonomous mobile robots, and pallet trucks.

**Problem space:** multi-camera tracking, real-time video pipelines, edge AI, and connecting perception outputs to operational systems.
