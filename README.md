## 👋 About

I'm a Software Engineer interested in the parts of software that make products dependable: **backend architecture, data flow, system behavior, and the engineering trade-offs behind performance and reliability.**

I enjoy working across the lifecycle — understanding a problem, designing the system, implementing the core logic, and validating how it behaves in practice. I'm particularly interested in applying machine learning where it creates measurable value, rather than treating AI as a feature for its own sake.
